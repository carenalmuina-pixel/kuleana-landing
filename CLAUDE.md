## Compliance — read this before writing or touching anything that ships

`instagram/compliance.md` is the authoritative, already-researched compliance doc for this repo — a real statute cross-reference (HRS ch. 431 art. 9, SB2876 / the NAIC Public Adjuster Licensing Model Act, HRS §431:13-102) mapped directly against this specific asset set, not a generic checklist. **Treat it as the primary source; don't re-derive the law from scratch.** Its standing rules, unchanged by this framework work:

1. License line — `HI Public Adjuster License #19246735 · Hawaiʻi DCCA Insurance Division · No recovery, no fee` — on every asset, structurally (footer/signature block), not optionally.
2. Never promise an outcome, amount, or timeframe. Hedge with "many," "can be" — never "most," "all," "will."
3. Disclose staged/AI-generated imagery **in the caption itself** (on-image stamps were deliberately removed at Caren's request; the caption line is the actual compliance control — never drop it).
4. No fee percentages in ads — "No recovery, no fee" only; percentages belong in the signed contract.
5. Solicitation rules tighten after a declared catastrophic event — pause urgency-driven CTAs and keep only educational content live, when in doubt.

The generalized version of this method (for any future regulated client, not just Kuleana) lives at `.claude/skills/lead-generation-structure/reference/compliance-framework.md`. Both docs agree: this is a first-draft-safe checklist, not a substitute for the business's own counsel doing a final read before anything goes out publicly.
